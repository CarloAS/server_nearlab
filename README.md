This repo contains all the main code to use NODS and test its applicability in NEST simulations.

### NODS-EBCC simulation

in order to run a simulation it has to be excecuted the script: test_simulation.py (all parameters are now set to default)
It is possible to customize the simulation by changing the condition with NO (w_NO) or without it (wo_NO) and set the background noise.

### Plot cell actvity and [NO] component

After the simulation has been completed, all the results can be analyzed using the jupyter notebooks contained in 'reproduce_results'
